## **SLIDE 3: What is Notion? The One-Minute Version** (3 min)
**Timing:** 0:07–0:10

### Visual
```
NOTION IN 4 WORDS:
Your organized digital workspace

═══════════════════════════════════

WHAT DOES IT DO?

📝 Write pages (like Google Docs)

📊 Create databases (like Excel, but smarter)
├─ Track courses, students, meetings
├─ Filter by date, person, status
├─ Automated calculations

🔗 Connect everything (the real magic)
├─ Link a course to its assignments
├─ Link a project to its team members
├─ Link a meeting to its decisions

📅 Calendar view
├─ See all deadlines at once

🔍 Search everywhere
├─ Find anything in seconds

═══════════════════════════════════

NOTION = Google Docs + Excel + Project Manager
        combined into ONE workspace
        that talks to itself
```

### Speaker Notes
"Think of Notion as a blank canvas. On that canvas, you can:
- Write notes (it's like Google Docs)
- Build a database to track things (it's like an Excel spreadsheet, but smarter)
- Connect those things together so they tell a story

Here's the key difference: In Excel, each row is separate. In Notion, you can *link* things. So a course knows which students are in it. A project knows which meetings discussed it. A deadline shows up in a calendar view *and* in your task list.

The magic is: you don't have to update information twice. Update once, and it shows up everywhere it matters.

And if you ever need to find something? Just search. Notion finds it, even if you only half-remember the name."

### Speaker Notes
"Here are the blocks you'll use most often. Don't memorize them—just know they exist. When you need one, type the slash command.

Text is your default. You write it like any Google Doc.

Headings break your page into sections. 'Meeting Notes,' 'To-Do Items,' 'Resources'—it helps organize the page so it's easy to skim.

Checklists are perfect for to-do lists, attendance tracking, grading rubrics where each criterion is a checkbox.

Tables look like spreadsheets. Good for schedules, rosters, assignments with due dates. You can sort, filter, color-code rows.

Callout is a highlighted box—great for saying 'Important!' or 'Read this first' or 'Deadline is Friday'.

Divider is just a line. It looks nice, breaks things up visually.

That's 80% of what you'll build with. Everything else is fancier versions of these ideas."

### Speaker Notes
"Here's the 'Tier 3' stuff—the power-user features. I'm only going to touch on this briefly because you're all still learning. But know it exists.

A database is basically a smart spreadsheet. It's like a table, but Notion watches it. You can filter it ('show only pending items'), view it different ways (table, calendar, board), and connect it to other databases.

The real magic is *connections*. A course database knows which students are in it. A student database knows which courses they're taking. Change one, the other updates.

Templates come with databases already set up. So when you duplicate a meeting notes template, you're actually duplicating a database—it's just formatted nicely.

Advanced users can create their own databases, link them together, set up automatic filters. But you don't need to do that today. Just know it's possible.

If you want to learn more later—and I mean this—there's an optional follow-up session we can do. For now, templates are your friend."

  Contact: [department secretary name] or Pooh

### Speaker Notes

If you're sharing something with students or the department, keep it updated. Stale information is worse than no information.

## **COMMON QUESTIONS ANSWERED**

**Q: Is Notion free?**
A: Yes! Notion is free for individual use. Workspaces like ours are also free for up to 10 members. Our department license is free (you get it because you work here).

**Q: Is my data safe?**
A: Notion encrypts data and stores it securely. You can set permissions so only the right people see sensitive info.

**Q: Can I access Notion on my phone?**
A: Yes! Download the Notion app (iOS/Android) and use the same login. It syncs automatically.

**Q: What if I accidentally delete something?**
A: You can recover deleted pages (ask Pooh to show you how). But the best practice: don't delete things—move them to an "Archive" section instead.

**Q: Can I export my data?**
A: Yes. Right-click a page → "Export" → choose PDF or Markdown. You own your data.

**Q: How is this different from Google Docs/Sheets?**
A: Notion combines docs, spreadsheets, and databases in one place with connections between them. Google Docs are great for writing; Notion is great for organizing everything.

**Q: Do I have to learn everything?**
A: No! Pick one template you'll use, customize it, and stop there if you want. Build more when you're ready.

**Q: Can I collaborate with others?**
A: Yes! Share any page. People can comment, edit (if you allow), and see real-time updates.
